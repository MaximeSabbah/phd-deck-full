Design choices

Some technical points:
  • Markovian, time structured problem
  • Hard constraints for boundaries and dynamic consistency
  • Modularity in problem formulation
Hard problem to solve in real-time if these are not addressed
Implementation details:
  • Pinocchio for efficient rigid body modeling
  • CasADi flexible framework for automatic differentiation and numeric optimization
  • Fatrop solver for fast (more global?) solution of constrained OCPs
J. Carpentier et al., The Pinocchio C++ library: A fast and flexible implementation of rigid body dynamics algorithms and their analytical derivatives, IEEE SII, 2019
JAE. Andersson et al., CasADi: a software framework for nonlinear optimization and optimal control, Mathematical Programming Computation, 2019
L. Vanroye et al., Fatrop: A fast constrained optimal control problem solver for robot trajectory optimization and control, IEEE IROS, 2023
